# 生成AIに判定させたときの指示文（付録A.4の照合に用いた判定）

このフォルダには、規則を作成する前の2026年9月末から10月にかけて、生成AIに取引条件を判定させたときの指示文を、そのまま置いている。
この判定は付録A.4で規則による判定と照合するためにだけ用い、本稿の分析には用いていない。
判定の結果は `data/published/earlier_ai_judgments.csv` にある。

生成AIには、Anthropic社のClaude Opus 5.5（`claude-opus-5-5`）を、Claude Code のサブエージェントとして用いた。
生成AIが読んだのは、書類から抜き出し、社名と証券コードを「■■」に置き換えた箇所だけである。
抜き出し方は `code/01_dataprep/document_passage_cutting.py` に記しており、規則による判定も同じ箇所を読んでいる。
生成AIには、収益率や株価、インターネット、ほかの案件の結果を見せていない。

各フォルダの `task_*.md` は判定の規則と出力の形を定めた指示文であり、`launch_prompt_*.txt` は生成AIを起動するときに送った文である。
起動文の `{N}` には、案件を分けた組の番号が入る。
指示文の中のファイルの場所は、筆者の計算機上の場所である。

| フォルダ | 読んだ書類 | 案件 | 照合に用いた条件 |
|---|---|---|---|
| `1_registration_statement_first_339/` | 公開買付届出書 | 最初に読んだ339件（試しに読んだ20件、続けて読んだ135件と184件） | 部分買付け、入札・競合あり、株主との応募・不応募の合意の記載なし、取締役会が応募を推奨しない、許認可の承認待ち、買付資金に借入・出資の予定なし |
| `2_registration_statement_2019_2021/` | 公開買付届出書（2019〜2021年は適時開示を含む） | 後から加えた2019〜2021年の案件 | 同上 |
| `3_opinion_statement_first_339/` | 意見表明報告書 | 最初に読んだ339件 | 株主優待の廃止、親子上場の解消 |
| `4_opinion_statement_2019_2021/` | 意見表明報告書 | 後から加えた2019〜2021年の案件 | 同上 |
| `5_price_negotiation_first_339/` | 1・2で生成AIが書いた価格交渉の要約 | 最初に読んだ339件 | 対象者との交渉による価格の引上げが確認されない |
| `6_price_negotiation_2019_2021/` | 同上 | 後から加えた2019〜2021年の案件 | 同上 |

注：
- `1_registration_statement_first_339/` では、試しに20件を読ませる途中で、一段落の要約を加える指示（`additional_message_1_paragraph.txt`）と、大株主の節を補った抜き出しで読み直させる指示（`additional_message_2_shareholder_reread.txt`）を追加で送った。
- `3_opinion_statement_first_339/` の起動文は記録が残っていない。判定の規則と出力の形は `task_iken.md` に定めたとおりである。
- 買付者へのファンドの関与とMBOの二つは、生成AIに判定させていない。付録A.4に記したとおり、それより前に案件ごとに作成していた買付者の種類の分類と照合した。
