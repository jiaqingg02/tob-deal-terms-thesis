# 公開買付けの取引条件と公表後の株価変動 — 分析コード

卒業論文「公開買付けの取引条件と公表後の株価変動」（慶應義塾大学経済学部、2026年度）の分析に用いたコードです。

## 内容

| フォルダ | 内容 |
|---|---|
| `program_vars/` | 公開買付届出書と意見表明報告書から、11項目の取引条件をキーワードと数値の規則で判定するプログラム。判定の規則はすべて `rules.py` にあり、条件ごとに1つの関数として書かれています。生成AIは判定に使っていません。 |
| `再現/` | 収益率・価格差の計算、分析表の作成、回帰分析、予測誤差の比較、頑健性の確認 |

11項目の取引条件：部分買付け、入札・競合あり、交渉で値上げされていない、買付者がファンド、MBO、大株主の応募契約なし、取締役会が中立、許認可の承認待ち、自己資金、株主優待の廃止、親子上場の解消。

## 実行方法

```
pip install -r requirements.txt
./再現/全部実行.sh
```

結果は `再現/結果/` に出力されます。主な結果は `02_回帰.py R1`（回帰）と `03b_予測比較_条件.py R1`（予測誤差の比較）です。

## データ

データはこのリポジトリに含めていません。入手先は次のとおりです。

- 公開買付届出書・意見表明報告書：EDINET（金融庁の電子開示システム）
- 公開買付けの適時開示：TDnet（東京証券取引所の適時開示情報伝達システム）。2019年と2021年の案件は IR BANK に保存された適時開示資料
- 株価：IR BANK（第三者のサイトのため、データの再配布はしていません）

コードは、これらを `data/`、`data_old/`、`fill_summary/` などのフォルダに置いた状態を前提にしています（パスは各プログラムの冒頭を参照）。
